Ayuda para configurar Google Cloud
  1. Activa Google Calendar API y crea un cliente OAuth para aplicación web.
  2. Registra http://localhost:3000/api/integrations/google/callback como URI autorizada.
  3. Copia las credenciales en el archivo .env y reinicia el servidor.
  4. Usa Importar eventos ahora para la importación inicial y las consultas incrementales posteriores.

Por seguridad, el Client Secret se configura únicamente en el servidor y nunca se muestra en el navegador.

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GOOGLE_REDIRECT_URI=http://localhost:3000/api/integrations/google/callback
INTEGRATION_ENCRYPTION_KEY=
